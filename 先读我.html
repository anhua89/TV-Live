这一版的变化

改动 使用方式
咪咕视频 “全部”列表末尾的 咪咕视频（网页），默认打开 咪咕官网
优酷视频 “全部”列表末尾的 优酷视频（网页），默认打开 优酷官网
列表首尾循环 第一项按上到最后一项；最后一项按下到第一项。长按上下可继续循环，松开停住，按确定才播放
网址与布局独立 三个网站分别记住自己的网址和桌面/兼容布局；修改咪咕不影响优酷或成都

两个新入口也在“其他”分组中，支持长按确定收藏。没有启用直播订阅时，三个网页入口仍会显示。新增入口追加在列表末尾，保留原有频道顺序。

你已反馈 1.3 成都网页可用；1.4 沿用其首页、遥控器光标、桌面适配、播放/全屏、新窗口跳转和诊断功能。咪咕、优酷从各自首页选择节目；成都仍会尝试定位电视直播区。

更新工程并发布

  1. 下载 JianshiTV-1.4-Complete-Source.zip，先完整解压，再进入 jianshi-tv-1.4。这一层直接能看到 app、tools、.github、gradlew.bat 和 version.properties。
  2. 打开 GitHub Desktop，选择 TV-Live，点 Fetch origin；出现 Pull origin 时先拉取。
  3. 点 Repository → Show in Explorer，打开这台电脑实际使用的仓库根目录。换过电脑或盘符也使用这个入口，不需要沿用旧绝对路径。
  4. 把解压后的 jianshi-tv-1.4 里面的全部文件和文件夹复制到仓库根目录，覆盖同名文件。不要再套一层项目文件夹，不要删除仓库自己的 .git。
  5. 回到 Desktop，Summary 填 Add Migu and Youku web channels and loop channel selection，点 Commit to main，再点 Push origin。
  6. 等这次提交的 Code checks 通过。
  7. GitHub → Actions → Build signed TV APK → Run workflow，保持正式发布选项开启。继续使用现有 Secrets，不重新配置签名。
  8. 成功后 Releases → v1.4 应有 JianshiTV-1.4.apk、update.json 和 channels.m3u。

本包已设置 versionName=1.4、versionCode=5。源码 ZIP 需要经过上述构建与发布，电视才能发现更新。若你的仓库已发布过 v1.4 或 versionCode 已达到 5，先同时递增两个版本值再发布，不能覆盖已发布的同版本。

在电视上升级

旧 App → 右键 → 检查应用更新 → 下载 → 系统确认安装。发布完成且电视能访问 GitHub Releases 后才能使用这一方式。

如果下载超时，在电脑从同一个 Release 下载 JianshiTV-1.4.apk，用 U 盘覆盖安装。保持同一应用标识和签名，不卸载原 App，可保留收藏、订阅和成都网页配置。

打开咪咕或优酷

  1. 按确定打开频道列表，左右切到 全部。
  2. 两个新入口在列表末尾：在第一项按一次 上，即可循环到最后的 优酷视频（网页）；再按一次上是 咪咕视频（网页）。也可切到 其他 查找。
  3. 选中后按确定，进入 App 内网页。方向键移动光标，确定点击网页中的节目、赛事或播放按钮。
  4. 顶部 咪咕首页 / 优酷首页 返回该网站首页；播放 / 全屏 可尝试播放视频或请求网页全屏，也可直接点击网页内部的播放/全屏按钮。
  5. 菜单键打开网页工具，可刷新、返回页面顶部、重新适配、放大/缩小、切换兼容布局、修改本频道网址或查看诊断。
  6. 返回键先退出视频全屏，再回到频道列表。要回到网页上一页，使用 网页工具 → 网页返回上一页。

完整网页遥控操作：方向键移光标，确定点击，翻页键滚动页面；菜单键开工具。网页内按上/下仍用于移动光标，首尾循环只作用于频道选择列表。

节目和会员登录按照网站提示操作。电脑截图中的登录状态不会复制到电视，App 不内置账号或会员；是否允许播放及对应权益以网站在当前设备上的提示为准。

电视验收

  1. 工具 → 使用说明确认版本 1.4。
  2. “全部”列表中确认两个独立新入口，第一项向上、最后一项向下均可循环。
  3. 长按上下跨过边界，确认继续选择且未提前打开网页或换台；松开后按确定才播放。再测试“收藏”和只有少量频道的分组。
  4. 分别进入咪咕和优酷，测试选节目、网页点击、播放声音/画面、全屏、返回和切后台停止声音。
  5. 返回成都频道，确认你当前可用的直播与布局仍正常；再播放央视和四川卫视。
  6. 收藏一个新入口，重启 App 后检查收藏保留；只改一个网站的布局，确认其他站点配置未改变。

如果网页能打开但节目黑屏，先看网站是否要求登录或提示播放限制，再用 菜单 → 网页诊断 查看媒体/网络提示；可试 切换兼容布局 或 在电视浏览器打开。网页加载完成不等于节目已经出画。
