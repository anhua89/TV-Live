简视 TV 1.2：成都频道改用网页

适用于已经安装本次新工程 1.0 / 1.1 的电视。应用名称仍是“简视 TV”，版本为 1.2 / versionCode 3。继续使用当前 TV-Live 仓库和同一份签名；不要重新生成密钥。

这次点击频道会发生什么

点击的频道 打开方式
央视、四川卫视、重庆卫视和其他非成都频道 原来的原生播放器；多源、测速、收藏等照旧
成都 CDTV / 成都电视台 打开 App 内的成都网页窗口
列表里没有成都台 在“成都”分组中补充“成都电视台（网页）”入口

“爱度网”尚未确认具体网址，因此默认先按成都电视台的“看度网”处理：https://www.cditv.cn/html/cdrtv/#live。这是共用入口，需要在网页内选择对应的 CDTV 频道；没有声称点击 CDTV-2 就已自动进入二套实播。

开发环境访问这个地址返回 HTTP 403，所以本包完成的是网页入口和操作功能，尚未验证成都节目能够播放。如果你说的是另一网站，或你已有可播放的具体页面，可以在电视里直接修改网址，无需重打包。网站自身的访问限制、视频格式和电视网页组件兼容性仍可能影响播放。

更新现有仓库

  1. 下载完整源码 ZIP 并解压，打开其中的 jianshi-tv-1.2。这一层应能看到 app、tools、.github、gradlew.bat 和 version.properties。
  2. 打开 GitHub Desktop，选择 TV-Live，点击 Fetch origin；如果出现 Pull origin，先拉取。
  3. 点击 Repository → Show in Explorer 打开当前仓库根目录。
  4. 将 jianshi-tv-1.2 里面的所有内容复制到仓库根目录，覆盖同名文件。不要把整个文件夹再套在仓库里面，不要删除仓库的 .git。
  5. Summary 填 Open Chengdu TV in web page，点 Commit to main，再点 Push origin。
  6. 等待最新提交的 Code checks 通过。
  7. GitHub → Actions → Build signed TV APK → Run workflow，保持发布选项开启。
  8. 正式发布完成后，Releases 应出现 v1.2，附件含 JianshiTV-1.2.apk、update.json 和频道目录。

源码包本身不能直接安装，也不会自动更新电视。必须先完成上面的构建与正式发布。如果已经发布过同名 v1.2，需要同时递增 versionName / versionCode 后再发；不要覆盖旧 Release。

在电视安装

电视能够访问 GitHub Releases 时：原 App → 右键 → 检查应用更新 → 下载 → 系统确认安装。

如果检查或下载超时：在电脑从同一个 Release 下载 JianshiTV-1.2.apk，用 U 盘覆盖安装。沿用原来四项 Secrets 中的签名材料，才能保留收藏和设置；不需要先卸载。

成都网页操作

  1. 打开频道列表，左右切到 成都，选择成都频道并按确定。
  2. 页面加载后，方向键移动红色光标，确定键点击网页的播放按钮或频道按钮。
  3. 顶部按钮可返回频道列表、刷新网页、修改网址、打开工具。菜单键也可以随时打开网页工具。
  4. 频道加减键或翻页键可滚动网页。网页工具中可放大、缩小、返回网页上一页或使用电视浏览器打开。
  5. 网页视频进入全屏后，第一次返回退出全屏；再按返回回到原来的频道列表。

“网页已加载”仅指页面完成载入，不表示直播已出画。若网页内没有播放画面，先确认网站是否仍提供该频道，或改用已在你家网络验证可用的页面。

修改网页地址

成都网页中按 菜单 → 修改成都网页地址，输入你确认可用的完整网址，选择 保存并打开。该地址由成都频道共用，不会改央视、卫视的订阅或播放方式。也可以点 恢复默认。

如果电视显示网页组件不可用，可以试 菜单 → 在电视浏览器打开。若没有浏览器，可返回频道列表继续看其他频道。
