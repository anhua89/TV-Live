更新源码并发布

  1. 完整解压 JianshiTV-1.5-Complete-Source.zip，进入 jianshi-tv-1.5。这一层直接能看到 app、tools、.github、gradlew.bat 和 version.properties。
  2. GitHub Desktop 选择 TV-Live，先 Fetch origin，有更新时 Pull origin。
  3. Repository → Show in Explorer 打开当前电脑使用的仓库根目录。
  4. 将 jianshi-tv-1.5 里面的全部文件与文件夹复制进去，覆盖同名文件；不要再套一层目录，也不要删除仓库自己的 .git。
  5. Summary 填 Fix video website layout and loading recovery，点 Commit to main → Push origin。
  6. 等最新提交的 Code checks 通过。
  7. GitHub → Actions → Build signed TV APK → Run workflow，保留正式发布选项。沿用已有 Secrets，不重新生成签名。
  8. Releases → v1.5 应有 JianshiTV-1.5.apk、update.json 和 channels.m3u。

电视端：旧 App → 右键 → 检查应用更新 → 下载 → 系统确认安装。也可从同一个 Release 下载 APK，用 U 盘同签名覆盖安装，不卸载原 App。源码 ZIP 本身不能直接安装。

如果旧版网页已经卡住，先通过电视主页键离开，再从电视系统的应用管理中关闭简视 TV，重新打开后检查更新。

本包的版本值已设置好。若仓库已发布 v1.5 或 versionCode 已达到 6，先同时递增版本值再发布，不能覆盖已有正式版本。

安装后的测试顺序

  1. 工具 → 使用说明确认 1.5。
  2. 进入咪咕，先检查首页大小；仍不合适时，菜单 → 重新适配屏幕 / 缩小网页。
  3. 选择一个节目，方向键将光标移到视频区域，再按确定。顶部 播放 / 修复 → 尝试播放 / 显示控制条 可请求播放已存在的视频。
  4. 咪咕或优酷仍黑屏/一直加载时，直接按遥控器 菜单 → 播放修复 → 切换手机网页。这会重新打开网页组件；对官网已确认的节目路径，尽量保留当前节目 ID。手机网页不是安装手机 App。
  5. 还可以在 播放修复 中选 重新打开当前网页，或 在电视浏览器打开。重新打开不会主动清除网站 Cookie；外部浏览器的登录状态由浏览器自身保存。
  6. 测试全屏、返回列表、切后台停止声音，再检查成都、央视、四川卫视与列表循环。

切换网页版本会分别记住咪咕和优酷的选择，互不影响。网站可能要求重新登录、验证或打开官方 App；未知路径保持原地址，不猜测视频链接。网站没有创建视频元素时，应用不会用一个假的播放按钮冒充播放器。

如果官方 HTTPS 页面申请受保护视频标识，电视会显示网站地址并询问是否允许本次使用。此项用于网站正常申请播放许可；账号、会员和设备条件仍由网站检查。应用不授予摄像头或麦克风权限。

仍不能播放时需要的反馈

请在故障页面按 菜单 → 播放修复 → 查看网页诊断，拍下这一页反馈。它比再次拍“加载中”更有助于区分问题，包含：

  • 当前页面、桌面/手机模式与浏览器内核版本。
  • 网页是否创建视频、是否提供视频数据、媒体网络状态、视频尺寸与媒体错误码。
  • 脚本等待时间、网页进程是否无响应，以及网络/脚本提示。

页面与资源地址会去除查询参数和片段，不显示 Cookie。检测到视频进度也不等于节目画面、声音和持续稳定性全部通过。
